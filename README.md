- Версия Go: `go version go1.27.3 darwin/arm64`.
- Редактор: VS Code.

## Выполнено

В репозитории нет исполняемых файлов, паролей и личных данных.

Откройте терминал в папке проекта, где находятся `main.go` и `go.mod`.
